# Eventos de muestra para probar las reglas SSH del honeypot (conexiones y comandos).
#
# Dos formas de usarlo:
#   A mano, en el manager:        sudo /var/ossec/bin/wazuh-logtest     (pegar UNA linea que no empiece con #)
#   Automatico, en el manager:    sudo python3 tests/run_logtest.py
# El CI corre un modelo offline de las reglas con estos mismos casos (tests/rule_model.py). Es una
# aproximacion: la prueba de verdad es run_logtest.py en el manager.
#
# Las lineas "#@" las leen esos programas. Se aplican al evento que tienen debajo:
#   expect=ID[,ID]   la regla que tiene que disparar (con varias, vale cualquiera)
#   not=ID           una regla que NO tiene que disparar
#   repeat=N         mandar el evento N veces; vale si la esperada dispara en alguna de las N
#   session=NOMBRE   los casos con el mismo nombre comparten estado (reglas de frecuencia y correlacion)
#   setup            caso de preparacion: se manda pero no se evalua
#   needs=cdb        solo corre con --cdb (hace falta la lista registrada en ossec.conf)
# Las IPs son de documentacion (RFC 5737), no son atacantes reales.
